# um-resume-as-a-code
Utkarsh Mankad, Resume as a Code. To maintain master + company-wide resumes.

While applying with a new resume for a company, follow these steps - 

1. Cut a new branch with the name - apply/<company-name>
2. Make changes in the main.tex file > commit > push
3. Generate a tag - v(date)-(company name)
4. Follow these commands to activate the workflow
   > git tag name
   > git push origin --tags
5. Check for the Workflow execution in the Actions section for any errors
